## Gun Buddy Select 0.1.0

First version. Pick which gun buddy a normal deploy puts down (the game's own, any of the four that A+B mixes, or Random), and optionally make A+B put down your pick too.

### How to install
1. Download `btga_gunbuddy_mod.nrm` below.
2. Open the BattleTanx: Global Assault recomp and go to the Mods tab.
3. Drop the `.nrm` file in, turn the mod on and set its options.

Needs the BattleTanx: Global Assault recomp 0.1.8 or newer.
